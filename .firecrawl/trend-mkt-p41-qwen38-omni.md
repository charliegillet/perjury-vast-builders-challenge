# Alibaba's Qwen3.8-Omni-Flash Slashes Audio Pricing 98% and Drops Open Weights

Alibaba's Qwen team launched Qwen3.8-Omni-Flash on September 18, cutting audio API pricing more than 98% and beating its predecessor by 26% across 30 benchmarks. The catch: unlike past Qwen releases, this one ships API-only, with no open weights for developers to self-host.

_Alibaba's Qwen team released Qwen3.8-Omni-Flash on September 18 with a blunt pitch: make audio and video agents cheap enough to use, but keep this model behind hosted access for now._

Qwen3.8-Omni-Flash is built for the messy work developers actually want to hand to a model. It accepts text, images, audio and video, then returns text. QwenCloud's model page lists a 1 million token context window, with 991,000 tokens of input and 131,000 of output. Feed it a two-hour meeting recording, a deck of slides and a chart. It should answer from the whole pile without making you stitch together a speech model, a vision model and a text model yourself.

The price is the part that lands first. QwenCloud lists the hosted model at $0.15 per million input tokens and $0.47 per million output tokens, with implicit cached input at $0.016 per million. The Decoder reported that Qwen estimates audio input at under one cent per hour, while one minute of 720p video with audio, sampled at one frame per second, costs about 20 cents before response tokens. That changes the math for meetings, call reviews and long video files. It does not make every workflow free. It does make many of them stop looking silly on a bill.

Cheap is not enough.

Qwen's own September 18 release says the model improved by more than 25% on average across 29 evaluations compared with Qwen3.5-Omni-Plus. The useful rows are not the broad victory lap. They are the agent and meeting rows, where WildClawBench-MM rose from 34.5 to 71.0 and AgenticVBench climbed from 14.5 to 36.8. UniClawBench reached 69.6, barely ahead of Google's Gemini 3.8 Flash score of 69.0 in Qwen's table. On AgenticVBench, though, Gemini still led at 45.0. You should read that plainly: Alibaba has a strong launch table, not a clean sweep.

## The Hosted Turn

Here's the part developers will notice after the price. Qwen3.8-Flash-Next has open weights on Hugging Face and GitHub under Qwen's own pages. Qwen3.8-Omni-Flash does not arrive the same way. QwenCloud and Alibaba Cloud Model Studio present it as a hosted model, with OpenAI-compatible API access through DashScope and Model Studio. Qwen Chat gives you a front door. The weights are not the front door.

That is a real trade. Qwen's open releases helped it win attention from developers who wanted to run a model on their own hardware, fine-tune it, inspect it and avoid being tied to one vendor's endpoint. A hosted-only omni model asks for a different kind of trust. The bill may be low. The dependency is still there.

Frankly, Alibaba can make a good case for doing it this way. Audio and video agents are not just model weights. They need file handling, tool calls, long-context caching, realtime paths and enough infrastructure to keep latency under control. The QwenCloud page says the model supports function calling, structured outputs, batching, web search and fine-tuning. Those are product features, not just lab claims.

## The Tools Around It

Alibaba also published Qwen-MM-Plugins, an Apache-2.0 project meant to help agent frameworks use the model's multimodal abilities. The Decoder said the plugins cover video editing, speaker recognition, PDF video notes and reusable workflows for tools such as Claude Code, Gemini CLI and Qwen Code. That's a lot of ground. Qwen-Live Harness is pitched as the realtime side, letting developers build camera-and-microphone interactions around Qwen's live model path.

Those companion tools matter because the model's pitch is not a chatbot that happens to hear audio. It is an agent. It can watch, listen, call tools and produce a finished answer. If you're building a live meeting assistant, a video research workflow or a review system for support calls, the difference between a cheap demo and a usable product is usually everything around the model.

Alibaba is not being subtle. It wants developers to compare Qwen3.8-Omni-Flash with Gemini Flash and GPT-style multimodal APIs on price, context and workflow coverage. On price, the comparison is uncomfortable for rivals. On openness, it is uncomfortable for Alibaba. The company has made the hosted product cheap enough that many teams will try it anyway.

That is the test now. Developers will forgive a closed endpoint if it saves real money and handles real files. They will not forgive it if the low price comes with shaky availability, missing regions or awkward tool support. Cheap access gets Alibaba into the room. The model still has to stay useful once developers build around it.
