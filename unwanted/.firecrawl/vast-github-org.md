# Open Source at VAST

[Permalink: Open Source at VAST](https://github.com/vast-data#open-source-at-vast)

Welcome! Here you will find code labs, code snippets, reference applications, open source projects, SDKs and infrastructure tools as you build on VAST.

The [VAST AI Operating System](https://www.vastdata.com/platform/ai-os) unifies storage, database, and compute to transform data into action. The software platform is built from ground up to manage and process massive amounts of unstructured data (files, objects, tables, vectors) at scale:

[![image](https://github.com/vast-data/.github/raw/main/profile/images/vast-ai.png)](https://github.com/vast-data/.github/blob/main/profile/images/vast-ai.png)

## SDKs and Tools

[Permalink: SDKs and Tools](https://github.com/vast-data#sdks-and-tools)

- **[Python SDK](https://github.com/vast-data/vastpy)**: Python SDK for VAST Management System (VMS)
- **[Go SDK](https://github.com/vast-data/go-vast-client)**: Go SDK for VAST Management System (VMS)
- **[VAST Management System MCP](https://github.com/vast-data/vast-admin-mcp)**: MCP server for AI assistants to monitor and manage VAST clusters
- **[DataEngine CLI](https://github.com/vast-data/dataengine-cli)**: CLI to manage VAST DataEngine functions, pipelines, triggers, and compute resources
- **[Database SDK](https://github.com/vast-data/vastdb_sdk)**: Python SDK for VAST Database and Catalog via PyArrow-compatible operations
- **[Orbit](https://github.com/vast-data/Orbit)**: Complete data science toolkit for VAST Database. Scikit-learn-like API with SQL/Python flexibility.
- **[Database Connectors](https://github.com/vast-data/vast-db-connectors)**: VAST Connector for third-party query engines (Trino and Spark)
- **[Arrow Database Connectivity](https://github.com/vast-data/vastdb-adbc-driver)**: Arrow database driver to query VAST Database
- **[Ansible](https://github.com/vast-data/vast-ansible)**: Ansible modules to automate VAST infrastructure with idempotent, declarative modules for views, policies, authentication, and networking
- **[Terraform](https://github.com/vast-data/terraform-provider-vastdata)**: Terraform provider to manage VAST infrastructure
- **[Kubernetes CSI driver](https://github.com/vast-data/vast-csi)**: Kubernetes CSI driver to integrate VAST storage with container workloads
