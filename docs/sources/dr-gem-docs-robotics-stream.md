# Gemini Robotics ER 2 streaming

- On this page
- [Documentation](https://ai.google.dev/gemini-api/docs/models/gemini-robotics-er-2-streaming-preview#documentation)
- [gemini-robotics-er-2-streaming-preview](https://ai.google.dev/gemini-api/docs/models/gemini-robotics-er-2-streaming-preview#gemini-robotics-er-2-streaming-preview)

Gemini Robotics ER 2 Streaming is a vision-language model (VLM) for robotics
optimized for real-time text streaming using the Live API. It accepts text,
image, video, and audio input and supports bidirectional streaming with
function calling.

[Try in Google AI Studio](https://aistudio.google.com/prompts/new_chat?model=gemini-robotics-er-2-streaming-preview)

## Documentation

Visit the [Live API for robotics](https://ai.google.dev/gemini-api/docs/robotics-streaming) page for
full coverage of features and capabilities.
